# RECURSIA — дизайн игры

> «Миры внутри миров. Симуляция внутри симуляции.»

## Суть
Каждый **мир** — это поле клеточного автомата 64×64, разделённое на 64 **территории** 8×8.
Эволюция клеток считается **прямо в смарт-контракте** (битборд, до 8 поколений за тик).
Любая территория может стать порталом в **дочерний мир** — свою симуляцию со своими
законами физики, глубиной до 7 уровней. Жизнь из дочернего мира может **прорваться** обратно в родительский.

## Игровой цикл
1. **Займи клетку-территорию** (`acquire`). Цена всегда объявлена, любой может выкупить её
   по этой цене (налог Харбергера: платишь % от своей цены каждую эпоху → завышать невыгодно, занижать опасно).
2. **Посади жизнь** (`plant`) — 8×8 узор (глайдер, осциллятор, свой). Стоимость сжигается.
3. **Мир тикает** (любой keeper), население твоей территории копит **очки эпохи**.
4. В конце эпохи мир получает **эмиссию** пропорционально сожжённому в нём, и она делится между
   владельцами по очкам. Забираешь через `collect` → `withdraw`.
5. **Открой дочерний мир** на своей территории (`create_child_world`): выбери законы физики (модуль),
   комиссию архитектора (до 30% налога Харбергера в этом мире) — и получай 15% с каждого его тика как держатель хост-территории.

## Новые ончейн-механизмы
| Механизм | Что нового |
|---|---|
| **Рекурсивные миры** | дочерние миры — отдельные PDA, привязанные к территории хоста; тик ребёнка платит хосту; если на хост-территории вымерла жизнь, ребёнок **засыпает** (Dormant) |
| **Прорыв (Breach)** | мир, державший население ≥ 400 достаточно долго (резонанс 64), вбрасывает глайдер в клетку хоста — жизнь «протекает» между уровнями симуляции |
| **Законы физики как рынок** | любой игрок регистрирует правило B/S (модуль) и получает роялти с миров, которые его используют |
| **Эмиссия — ребейт за сожжённое** | награда ≤ 90% реального сжигания: фарм невозможен по построению |
| **Harberger-территории** | постоянный честный рынок клеток без аукционов и без «сквоттеров» |
| **Восстание** | держатели ≥ 2/3 клеток (минимум 8) могут свергнуть архитектора мира: мир освобождается, комиссия архитектора обнуляется навсегда, накопленное уходит бывшему архитектору |
| **ИИ-жители по доверенности** | `AgentPermit`: у агента отдельный бюджет, лимит на эпоху, макс. цена, срок, область — всё в контракте |

## Игроки и ИИ
- **ИИ-жители** четырёх характеров: Садовник (сажает и держит), Экспансионист (скупает дешёвое),
  Спекулянт (перепродаёт), Демиург (создаёт дочерние миры). Они **не LLM**: читают только ончейн-числа,
  поэтому prompt injection невозможен.
- **Люди** играют теми же инструкциями, что и ИИ; преимуществ у ИИ нет.
- Игрок может **нанять ИИ-жителя** со своим бюджетом: агент ходит за него 24/7, но не может потратить больше лимита и не может вывести деньги.

## Режимы клиента
- **Песочница** — те же правила (эталонная модель, побитово совпадающая с контрактом по 24 кросс-векторам), ИИ-соседи, ускоренное время. Для обучения и баланса.
- **Devnet/Mainnet** — реальные аккаунты программы, подпись через Wallet Standard, превью каждой транзакции через `simulateTransaction`.
