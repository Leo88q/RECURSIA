# RCR — токеномика

## Параметры токена
| | |
|---|---|
| Тикер | **RCR** (Recursia) |
| Стандарт | классический SPL Token (без Token-2022 расширений) |
| Decimals | 6 |
| Эмиссия | **1 000 000 000 RCR, фиксировано** |
| Mint authority | отзывается в `genesis` навсегда (`set_authority → None`), проверяется контрактом |
| Freeze authority | никогда не задавалась |

## Распределение в genesis (зашито в контракт)
| Доля | Кому | Где лежит | Как расходуется |
|---|---|---|---|
| 45% | **Reward pool** | PDA `reward_pool` | только эмиссией эпох, по правилам контракта |
| 10% | **Казна студии** | PDA `treasury` | только через публичное предложение `TreasurySpend` с timelock ≥ 48ч |
| 45% | **Distribution** | токен-аккаунт получателя (multisig) | ликвидность, аирдропы игрокам, гранты создателям модулей — по публичному плану |

## Потоки токена
```
             ┌──────────── tick_cost (энергия мира) ────────────┐
             │                                                  │
  cranker 2% │  protocol 10% → казна    royalty ≤5% → автор модуля
             │  host 15% → держатели хост-территории (или энергия хоста)
             │  ОСТАТОК ≥ 30% → СЖИГАНИЕ (MIN_TICK_BURN_BPS)
             ▼
  plant_cost → 100% сжигание
  world_create_fee / module_register_fee → fee_burn_bps (50%) сжигание, остальное — казна
  налог Харбергера → architect_fee_bps (≤30%) архитектору мира, остальное → энергия мира (позже сгорит на тиках)
  цена территории → продавцу (claimable)
```

## Эмиссия — «ребейт за реальное сжигание»
Раз в эпоху (`epoch_slots`, по умолчанию 216 000 слотов ≈ 1 сутки):

1. `advance_epoch`: бюджет эпохи = `reward_pool × emission_rate_bps` (по умолчанию 0.5%, максимум 2%).
2. `claim_world_epoch(world)`: мир получает
   `min( бюджет × burn_мира / burn_всех,  burn_мира × rebate_cap (90%),  остаток бюджета )`.
3. Награда делится между **владельцами** территорий пропорционально населению их клеток за эпоху (`scores`), доля бесхозных клеток уходит в энергию мира.

**Следствие:** получить из пула можно не больше 90% того, что ты сжёг. Любой фарм (сибилы, самоигра, wash) — строго убыточен; эмиссия — это скидка активным игрокам, а не печатный станок. Пул никогда не пополняется, поэтому эмиссия затухает геометрически, а сжигание продолжается → **долгосрочная дефляция**.

## Монетизация разработчика (студии)
| Источник | Размер | Где в коде |
|---|---|---|
| Протокольная доля каждого тика | `protocol_bps` = 10% от `tick_cost` | `splitTick` / `P/math.rs` |
| Комиссии создания мира и регистрации модуля | 50% от fee (остальное сжигается) | `create_*_world`, `register_module` |
| Роялти за собственные модули физики | до 5% каждого тика миров на этих правилах | `Module.accrued` |
| Казна 10% genesis | через timelock | `TreasurySpend` |

Студия зарабатывает, **пока игроки играют** (тики), а не на продаже токена — это проверяется инвариантом I5 в `econ-sim`.

## Монетизация игроков
- **Держатели территорий**: доля эмиссии по населению + доход хоста от дочерних миров + продажа клетки по объявленной цене.
- **Архитекторы миров**: комиссия `architect_fee_bps` (≤ 30%) с налога Харбергера, который платят держатели клеток их мира.
- **Авторы модулей** (любой игрок): роялти до 5% с каждого тика миров на их правилах.
- **Keeper'ы**: 2% `tick_cost` за каждый тик.
- **ИИ-агенты по доверенности**: действуют от имени владельца в рамках permit.

## Результаты econ-sim (дефолтные параметры, `npm run econ -- --quick`)
| Сценарий | emit/burn | Выручка студии за 6 эпох | Фармер | Медиана ИИ |
|---|---|---|---|---|
| baseline (12 ИИ) | ~45% | ~10 000 RCR | — | ≈ −375 RCR |
| self-farm attack | ~43% | ~7 200 RCR | **−37 900 из 40 000** | ≈ −450 RCR |
| whale pressure | ~45% | ~7 000 RCR | — | ≈ −465 RCR |
| delegated AI | ~44% | ~4 200 RCR | — | ≈ −345 RCR |
| thin market | ~21% | ~400 RCR | — | ≈ −500 RCR |

Все 7 инвариантов выполняются. **Вывод для калибровки:** при текущих параметрах средний игрок немного платит за игру (игра как сервис + дефляция). Для тестнета рекомендуется подобрать `harberger_bps`, `plant_cost` и `tick_cost` так, чтобы верхний квартиль активных игроков выходил в плюс; все параметры меняются только через 48-часовой timelock и ограничены константами контракта.
