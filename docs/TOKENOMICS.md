# SKR в RECURSIA — экономика

RECURSIA не выпускает свой токен. Валюта игры — **SKR**, токен экосистемы Solana Mobile (Seeker).
Игра не может напечатать, сжечь или заморозить SKR. Она только перераспределяет траты игроков:
**20% получает студия, 80% уходит в пул наград игроков.**

## Параметры токена
| | |
|---|---|
| Тикер | **SKR** (Seeker, Solana Mobile) |
| Mint | `SKRbvo6Gf7GondiT3BbTfuRDPqLWei4j2Qy2NPGZhW3` (константа `SKR_MINT` в `constants.rs` и `SKR_MINT_STR` в SDK) |
| Стандарт | классический SPL Token (без Token-2022 расширений) |
| Decimals | 6 |
| Предложение | ≈ 10,6 млрд SKR; инфляция задаёт Solana Mobile (10% в первый год, дальше снижается на 25% в год до 2%) |
| Mint authority | у мультисига Solana Mobile (Squads). **У RECURSIA её нет и никогда не будет** |
| Freeze authority | отсутствует (`None`). Контракт проверяет это в `initialize` |
| Курс для оценок | ≈ $0,019 (сентябрь 2026, Solscan). В контракте все цены заданы в SKR, курс на них не влияет |

**Подделки.** Существуют фальшивые «SKR» с тем же названием, например `BjUnECa5VouJmHGeQUjwuHNbKRK8BsihFW8t8RqQLE4F` (9 decimals).
Защита работает на трёх уровнях:
1. Сборка контракта для мейннета (`--features mainnet`) в `initialize` принимает только `SKR_MINT`.
2. Mint с freeze authority или с другими decimals отклоняется на любом кластере (ошибка `BadMint`).
3. Клиент и keeper сверяют `config.mint` со своим mint. Если он другой, клиент показывает «Контракт настроен на другой токен», а keeper не запускается.

## Счета протокола (PDA программы, SPL-аккаунты SKR)
| PDA | Что лежит | Как выходит |
|---|---|---|
| `reward_pool` | пул наград игроков | **только** наградами мирам в `claim_world_epoch`. Вывести пул не может никто, включая админа |
| `treasury` | доля студии | только публичным предложением `TreasurySpend` с задержкой ≥ 48 ч через мультисиг, и только из уже поделённой с сезоном части (`treasury_seen`, иначе `TreasuryLocked`) |
| `sponsor_pool` | спонсорский пул (взносы студии, партнёров, фанатов) | **только** мирам в `claim_world_epoch` — по живым клеткам. Вывести не может никто |
| `season_pool` | призовой фонд сезонов (25% дохода студии) | **только** призами топ-10 в `claim_season_prize`. Вывести не может никто |
| `claims` / world vault / permit vault | деньги игроков (выручка, депозиты, энергия, бюджеты агентов) | владельцу по его подписи, по правилам контракта |

Пул может пополнить любой через `fund_reward_pool(amount)`: студия на запуске, партнёры, спонсоры турниров.
Событие `RewardPoolFunded` публикует каждое пополнение. Спонсорский пул пополняется так же — `fund_sponsor_pool(amount)`
(событие `SponsorPoolFunded`).

## Потоки токена
```
  Каждая трата игрока S делится в math::split_spend:
      студия  = S × protocol_bps (20%, потолок в коде 25%)   → treasury
      пул     = S − студия                                     → reward_pool

             ┌──────────── tick_cost (энергия мира) ────────────┐
             │                                                  │
  cranker 2% │  studio 20% → treasury    royalty ≤5% → автор закона
             │  host 15% → держатели хост-территории (или энергия хоста)
             │  ОСТАТОК ≥ 30% → ПУЛ НАГРАД (MIN_TICK_POOL_BPS); по умолчанию 58–63%
             ▼
  plant_cost → split_spend (20% студии / 80% пул)
  world_create_fee / module_register_fee → split_spend
  налог Харбергера → architect_fee_bps (≤30%) архитектору мира, остальное → энергия мира (дальше уходит на тики)
  цена территории → продавцу (claimable)

  ⚛ quantum_commit → plant_cost × n: split_spend  +  залог 4×plant_cost × n → эскроу мира
       ├─ observe   → 5% залога наблюдателю (keeper/ИИ/игрок)
       ├─ re-arm    → 25% залога В ПУЛ (слот выпал из окна SlotHashes)
       ├─ collapse  → остаток залога владельцу
       └─ decohere  → 5% вызвавшему, остаток В ПУЛ

  ⚖ swap_offer (нейтральный мир) → plant_cost: 80% split_spend, 20% → эскроу (бонус резолвера)
                                  + премия → эскроу мира
       ├─ resolve → премия принявшему (claimable, при любом исходе), бонус резолверу
       └─ cancel  → премия обратно предложившему (claimable), бонус отменившему

  ⚗ register_module (закон игрока) → module_register_fee: split_spend;
       дальше автор получает royalty_bps (≤5%, неизменяемо) с КАЖДОГО тика каждого мира на этой физике
```
Штрафы квантовых ходов идут в пул целиком: доля студии с них не берётся, чтобы у студии не было стимула
к тому, чтобы игроки проигрывали.

## Награды эпохи: «ребейт за вклад в пул»
Раз в эпоху (`epoch_slots`, по умолчанию 216 000 слотов ≈ 1 сутки):

1. `advance_epoch`: бюджет эпохи = `reward_pool × emission_rate_bps` (по умолчанию 10%, максимум 20%).
2. Бюджет делится на две части:
   - **ребейт** (70%): мир получает `min( ребейт × вклад_мира / вклад_всех,  вклад_мира × rebate_cap (100%),  остаток )`;
   - **доля за эффективность** (30%, `EFFICIENCY_SHARE_BPS`): мир получает
     `min( доля × живые_клетки_мира / живые_клетки_всех,  вклад_мира × 200% (EFFICIENCY_CAP_BPS),  остаток )`.
     «Живые клетки» — сумма живых клеток на **занятых** участках по всем тикам эпохи, по всем мирам сразу
     (`World.score_owned_prev`, `Config.prev_total_score`; та же формула `math::world_sponsor`, что и у спонсорского пула).
   Здесь «вклад» — часть трат этого мира, ушедшая в пул (`sink_prev`). Доля студии во вклад не входит.
3. Награду делят **владельцы** территорий пропорционально населению их клеток за эпоху (`scores`).
   Доля бесхозных клеток уходит в энергию мира.

4. Тот же `claim_world_epoch` выплачивает и **спонсорскую** часть (см. ниже) — одной транзакцией, одной раздачей по очкам.

**Следствие.** Ребейт возвращает миру не больше 100% его вклада в пул, а 20% доли студии не возвращаются вовсе:
трата без живых клеток (сибилы, «сам с собой», wash) теряет не меньше **20%**. Всё, что сверх вклада, — это доля за
эффективность, и её получают только за живые клетки на своей земле. Её бюджет фиксирован (30% эмиссии эпохи) и делится
между всеми мирами, поэтому это **перераспределение от слабых игроков к сильным**, а не печать денег. Новых SKR игра не создаёт.

Почему так: econ-sim показал, что при потолке 90% и без доли за эффективность в плюс не выходил почти никто, даже
лучшие игроки. Выигрыш сильного игрока должен откуда-то браться; теперь он берётся из трат тех, чья жизнь вымирает.

Суммы сходятся в `GameModel.check()` и в инварианте I1 econ-sim: баланс SKR сохраняется точно, ничего не печатается и не сжигается.

## Спонсорский пул: награда за жизнь, а не за траты
Пул наград — это перераспределение денег самих игроков, поэтому в целом игроки в нём не могут выйти в плюс.
Спонсорский пул — внешний источник: его пополняют студия (маркетинговый бюджет), партнёры, фанаты.

1. `advance_epoch`: бюджет = `sponsor_pool × 10%` (`SPONSOR_RATE_BPS`), если в прошлой эпохе была хоть какая-то жизнь и траты.
2. Вес мира — **живые клетки на занятых территориях**, накопленные по тикам эпохи (`World.score_owned_cur`;
   сумма по всем мирам — `Config.cur_total_score`). Бесхозные клетки не считаются: платим за жизнь, которую кто-то поддерживает.
3. `claim_world_epoch`: мир получает `min(бюджет × вес_мира / вес_всех, вклад_мира × 100% (SPONSOR_CAP_BPS), остаток)`
   (`math::world_sponsor`). Мир, который ничего не внёс, не получает ничего, как бы «жив» он ни был.

Итого живой мир может вернуть до **400%** вклада (100% ребейт + 200% за эффективность + 100% спонсорских), но только
в рамках конечных бюджетов эпохи. Это намеренно
положительная сумма: сколько положили спонсоры — столько и раздадут, не больше (инвариант I12).
**Ферма «сама с собой»** в сценарии «sponsored farm» всё равно теряет ≈ 2,6 млн SKR: чтобы получить спонсорские,
нужны настоящие живые клетки и настоящие траты, а доля мира ограничена его вкладом.

## Сезоны: 25% дохода студии — в призы
- Сезон = 7 эпох (`SEASON_EPOCHS`, ≈ неделя). На каждом `advance_epoch` контракт берёт **25% нового притока в казну**
  (`treasury − treasury_seen`) и переводит в `season_pool`. Управление может тратить только оставшиеся 75%:
  `TreasurySpend` сверх `treasury_seen` отклоняется (`TreasuryLocked`), так что студия не может «обогнать» отчисление.
- Очки сезона = SKR, которые игрок **собрал** с живых клеток (`collect`: награды + доход хоста), `Player.season_points`.
  Очки считает контракт — подделать их нельзя (score injection закрыт).
- `season_submit` (любой может отправить за любого) вставляет игрока в топ-10 аккаунта `Season` — по одной записи на игрока,
  по очкам из его аккаунта. Для гонок безопасно: запись только растёт.
- При закрытии сезона фиксируются призы: доля места `[30, 20, 15, 10, 8, 6, 4, 3, 2, 2]%` фонда, **но не больше 25% очков победителя**
  (`SEASON_PRIZE_CAP_BPS`, `math::season_prize`). Неразыгранное переходит в следующий сезон.
- `claim_season_prize(rank)` может отправить любой (keeper делает это автоматически), деньги всегда идут в `claimable` победителя.

**Почему призы нельзя нафармить.** Без живых клеток очки `P` стоят не меньше `P / 0,8` трат (ребейт ≤ 100% вклада,
20% уходит студии), приз ≤ 25% × `P`: фарм возвращает не больше 0,8 × 1,25 = **1,0 от трат** — в лучшем случае ноль,
а с налогом Харбергера и арендой — убыток. В econ-sim фермер собирает очки и заявляет их — и остаётся в минусе на ≈ 2,6 млн SKR (I3).

Оговорка честности: собранные спонсорские деньги тоже дают очки. Мир, который реально держит живые клетки, может
получить больше своего вклада и приз сверху. Это не дыра, а смысл спонсорского пула: он платит за жизнь, и такой «фермер» —
обычный игрок, который делит конечный спонсорский бюджет с остальными пропорционально живым клеткам. Сверх бюджета,
положенного спонсорами, никто ничего не получит (I12).

## Турниры сезона: взнос → лучшие 30%
- Один турнир на (сезон, уровень). Уровни: «Открытый» — взнос `2 × plant_cost` (700 SKR), «Мастерский» — `20 × plant_cost` (7 000 SKR).
  Разные уровни не дают киту съесть банк новичков.
- `tournament_join` только в **первую эпоху** сезона (`TOURNAMENT_JOIN_EPOCHS`), до 40 участников (`TOURNAMENT_MAX_PLAYERS`),
  одна запись на кошелёк (PDA `entry` создаётся через `init`). **10% взноса — студии** (в казну, откуда 25% уходит в сезонный фонд),
  **90% — в банк** (`tournament_pool`, вывести не может никто).
- Очки — те же очки сезона, которые считает контракт (`Player.season_points`). `tournament_submit` может отправить любой.
- После конца сезона `tournament_settle` (любой) фиксирует призы: `ceil(30% участников)` мест, не больше 12, веса линейные
  (k, k−1, …, 1), но только для мест с очками > 0. Неразыгранное уходит **в пул наград игроков**, не студии.
- `claim_tournament_prize` (любой, keeper делает сам) зачисляет приз в `claimable` победителя.
- Сибилы бесполезны: каждый кошелёк платит взнос, а очки — это реально собранные с живых клеток SKR.
- Принятый риск: очки абсолютные, поэтому большой кошелёк с живыми клетками в среднем набирает больше. Смягчение — уровни взноса и потолок 40 игроков.

## Монетизация разработчика (студии)
| Источник | Размер | Где в коде |
|---|---|---|
| Доля каждой траты игроков | `protocol_bps` = 20% (потолок `MAX_PROTOCOL_BPS` = 25%) | `math::split_spend`, `common::user_spend` / `vault_spend` |
| …в том числе с каждого тика | 20% `tick_cost` | `math::split_tick` |
| Роялти за собственные законы физики | до 5% каждого тика миров на этих правилах | `Module.accrued` |
| Рейк турниров | 10% взносов | `tournament_join` |
| **минус** отчисление в призы сезонов | 25% притока в казну | `advance_epoch`, `season_pool` |

Чистая доля студии — 75% × 20% = **15% всех трат** (плюс роялти). Остальные 5% трат возвращаются лучшим игрокам сезона.

Студия зарабатывает, **только пока игроки играют**: продажи токена у неё нет. Это проверяет инвариант I5 в `econ-sim`.
В econ-sim студия получает 80–670 тыс. SKR за 6 эпох в зависимости от активности (≈ $1,5–13 тыс. по курсу выше).

## Монетизация игроков
- **Держатели территорий**: доля пула наград по населению + **спонсорский пул** по живым клеткам + доход хоста от дочерних миров + продажа клетки по объявленной цене.
- **Лучшие игроки сезона**: призы топ-10 из 25% дохода студии (не больше 25% собственных очков).
- **Сильные игроки вообще**: доля эмиссии за эффективность (30% бюджета эпохи по живым клеткам, до 200% своего вклада).
- **Участники турниров**: лучшие 30% делят 90% взносов.
- **Архитекторы миров**: комиссия `architect_fee_bps` (≤ 30%) с налога Харбергера, который платят держатели клеток их мира.
- **Авторы законов физики** (любой игрок или ИИ-физик): роялти до 5% с каждого тика миров на их правилах.
  Лаборатория показывает жизнеспособность закона, а ИИ-демиурги выбирают физику с весом «жизнеспособность²»,
  так что живой закон сам находит миры и платит автору.
  Окупаемость при параметрах по умолчанию: непрерывно тикающий мир даёт 216 000 / 150 = 1 440 тиков в сутки × 700 SKR × 2,5% ≈ **25 200 SKR в сутки**
  роялти. Сбор регистрации 350 000 SKR окупается примерно за 2 недели на один активный мир. Высокий сбор защищает рынок законов от спама
  клонами. В песочнице время идёт в 24 раза быстрее, и сбор уменьшен в 20 раз (17 500 SKR).
- **Торговцы исходами** (нейтральные миры): премия за принятый риск SWAP; хедж сильного блока или ставка слабым блоком на чужую жизнь.
- **Keeper'ы**: 2% `tick_cost` за каждый тик + 5% залога за каждое квантовое наблюдение/декогеренцию + 20% сбора за каждое разрешение/отмену SWAP.
- **ИИ-агенты по доверенности**: действуют от имени владельца в рамках permit.

## Цена входа
Минимальный вход: занять свободную клетку за 700 SKR, депозит налога на одну эпоху 3,5 SKR и первая посадка 350 SKR.
Итого **1 053,5 SKR ≈ $20** плюс до 0,00549 SOL аренды аккаунтов (её получает сеть, а не студия).
Юнит-тест `app/test/costs.test.ts` проверяет эти числа.

2. Главный рычаг — подсказки клиента перед посадкой. Новичок без них тратит ≈ 3/4 кошелька на посадки, которые вымирают
   (в среднем ≈ 140 посадок по 350 SKR). С подсказками в плюсе больше половины новичков. Честная цена: без подсказок студия
   зарабатывает на ≈ 10–15% больше — на ошибках новичков. Мы сознательно отказались от этих денег.
3. Доля за эффективность и потолок ребейта 100% превращают пул в перераспределение **от слабых к сильным**: плюс сильных
   оплачивают траты на вымершую жизнь, а не студия и не новые токены (I1, I2).
4. Фарм по-прежнему убыточен: фермер теряет ≈ 2,6 млн SKR (I3), с доли за эффективность он ничего не получает без живых клеток.
5. Турниры за 20 эпох: 6 турниров, взносы 43–48 тыс. SKR, призы 25–26 тыс. SKR, остальное — рейк и возврат в пул.
6. Утаивание квантового исхода по-прежнему убыточно (I8). Все 14 инвариантов выполняются во всех прогонах.
7. Оговорка: поведение «новичка с подсказками» — модель (он пропускает посадку, если прогноз ≤ текущего населения участка).
   Реальных людей надо проверить на devnet.
