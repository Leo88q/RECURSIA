# RECURSIA

**Миры внутри миров. Ончейн-игра клеточной эволюции на Solana на токене SKR (Solana Mobile), с живыми игроками и ИИ-жителями.**

Своего токена у игры нет: 20% всех трат игроков получает студия, 80% уходит в пул наград и возвращается
игрокам за живые клетки. Минимальный вход — 1 053,5 SKR (≈ $20).

Каждый мир — это клеточный автомат 64×64, эволюция которого считается прямо в смарт-контракте.
Игроки владеют территориями по налогу Харбергера, сажают жизнь, открывают дочерние миры со своими законами физики,
а жизнь из вложенных симуляций может прорваться наверх.

**⚛ Квантовые миры.** Законы физики могут быть вероятностными: энтропию каждого тика даёт хеш
заранее назначенного слота Solana, поэтому будущее такого мира нельзя просчитать офчейн —
ни человеку, ни ИИ. Игроки сажают клетки в **суперпозицию** двух паттернов (честный commit-reveal),
любой **наблюдатель** фиксирует исход за награду, при **коллапсе** паттерн может **туннелировать**
к соседу, а **запутанная** клетка в другом мире получает противоположное состояние.
Не раскрыл вовремя — **декогеренция** отправляет залог в пул наград. Подробно — [GAME_DESIGN](docs/GAME_DESIGN.md#квантовый-слой-).

**⚖ Нейтральные миры.** Мир без архитектора и его налога, где действует только квантовая физика и игроки
**торгуют исходами**: квантовый SWAP меняет две клетки местами с согласованной вероятностью p. Исход решает хеш
будущего слота, а принявший получает премию за риск. После принятия сделка обязательна для клеток, так что
сбежать от проигрыша не получится.

**⚗ Лаборатория физики.** Любой игрок пишет свои (квантовые) законы B/S/qB/qS, видит живой предпросмотр,
кривую населения и жизнеспособность, публикует закон ончейн и получает до 5% роялти с каждого тика всех
миров, которые его используют. ИИ-демиурги выбирают физику по жизнеспособности, а ИИ-физики сами изобретают
законы и конкурируют с людьми за роялти.

## Интеллектуальная собственность

Лицензионного файла в репозитории **нет**: по умолчанию «All rights reserved» — копирование,
изменение и использование кода разрешены только по явному письменному согласию. Решение открыть код
(под какой лицензией) принимает команда до mainnet-запуска; до этого время публичность репозитория
обеспечивает проверяемость (verified build), но не даёт прав.

## Структура
```
programs/recursia/   смарт-контракт (Anchor 0.31.1): 42 инструкции, симуляция на битбордах,
                     квантовый слой (quantum.rs + instructions/quantum.rs),
                     нейтральные миры и SWAP (instructions/swap.rs)
packages/sdk/        TypeScript SDK без @coral-xyz/anchor: PDA, раскладки, инструкции,
                     эталонная модель GameModel (бит-в-бит с контрактом), ИИ-агенты, econ-sim,
                     лаборатория физики (physics.ts: проверка, предпросмотр, мутации, жизнеспособность)
keeper/              permissionless crank-бот (тики, эпохи, клеймы, форклоужеры, прорывы,
                     квантовые наблюдения и декогеренция, разрешение и очистка SWAP)
app/                 клиент (React + Vite): лендинг с правилами и стоимостью входа, песочница с ИИ, лаборатория физики и полный ончейн-режим
                     (Wallet Standard, пайплайн транзакций с симуляцией/превью, live-подписки,
                     все действия игрока), собственная графика (иконки, фон, ключевой арт, PWA/OG),
                     hash-роутинг, адаптив, a11y, CSP/заголовки, Docker
tests/vectors/       кросс-реализационные векторы Rust ↔ TypeScript
scripts/             CI-гигиена: скрытый unicode, supply-chain, аннотации ошибок
```

## Быстрый старт
```bash
npm ci --ignore-scripts
npm test                  # SDK (58) + keeper (9) + клиент (60) тестов
npm run econ -- --quick   # экономическая стресс-симуляция: 10 сценариев, 14 инвариантов, PnL по ролям, доля игроков в плюсе
npm run dev               # клиент на http://localhost:5173 (режим «Песочница» работает без блокчейна)
```

Адреса клиента: `#/` — лендинг (философия, что за игра, как начать, стоимость входа, все правила, FAQ; разделы `#/philosophy`, `#/start`, `#/price`,
`#/rules`, `#/faq`), `#/play` — песочница, `#/lab` — лаборатория, `#/chain` — ончейн-режим. Все цифры лендинга считаются
из `DEFAULT_PARAMS` и размеров аккаунтов (`app/src/lib/costs.ts`, тест `app/test/costs.test.ts`), поэтому не расходятся с контрактом.
Минимальный вход при параметрах по умолчанию — 1 053,5 SKR ≈ $20 (клетка 700 + депозит налога 3,5 + посадка 350) и не больше 0,00549 SOL аренды и комиссий.

Контракт: `cargo test -p recursia`, `anchor build` (см. `docs/DEPLOY.md`).

## CI
Каждый push проверяет: скрытый unicode, скомпрометированные пакеты, `npm audit`, юнит-тесты и clippy программы,
SBF-сборку и сверку IDL ↔ SDK, тесты SDK/keeper/клиента, econ-sim, сборку клиента,
бюджет бандла и синхронность заголовков безопасности для всех хостингов.

> ⚠️ Внешний аудит ещё не проводился. Не используйте в mainnet до завершения пунктов раздела 10 в `docs/DEPLOY.md`.
